# Documentation Map

This release keeps the documents needed to understand, reproduce, and audit the
benchmark protocol.

- `WAM_SCOPE_AND_UNIFIED_PROTOCOL_V1_ZH.md`: scope, accepted WAM output forms,
  CFAC/CCFC/FAU/FCS definitions, and fail-closed rules.
- `WAM_SUBMISSION_V1_ZH.md`: public submission contract and validation rules.
- `BENCHMARK_V3_PROTOCOL_AUDIT_20260904_ZH.md`: benchmark-v3 selection and
  leakage audit.
- `DRIVEWAM_BENCHMARK_V3_RESULTS_20260905_ZH.md`: reference run and main-table
  numbers on the 1,000-sample NAVSIM benchmark.
- `MEASUREMENT_ABLATION_20260905_ZH.md`: pre-registered resolution and heading
  shadow checks; these do not change the frozen main score.
- `RELEASE_MANIFEST_V1_ZH.md`: what is included in this public release and what
  remains private.
- `IAC_FROZEN_PIPELINE_V1.mmd`: compact architecture diagram.

Private image frames, ground truth, WAM checkpoints, generated videos, and
server-specific run paths are intentionally excluded from this repository.
